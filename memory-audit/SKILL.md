# memory-audit（记忆深度对账）

对记忆库做周期性全面核验，把记忆库拉回与仓库现实一致（判据与动机见 memory-discipline.md「两问测试」）。

**何时跑**：每收口满 2-3 行（票数或轮次；checkpoint 清单尾行有计数）；用户感觉「AI 又开始犯常识错」时；/orient 转介时（重写手术、孤岛合并、重建索引）；点名「体检记忆」时。

先读 [`../checkpoint/references/memory-discipline.md`](../checkpoint/references/memory-discipline.md)（读不到→停下告知用户，尝试从套件 git 副本恢复）。

## 过程

1. **盘点**：列记忆目录全部文件（行数/字节），读 MEMORY.md 与每条记忆全文——全库扫描与证据 grep 派只读子代理（每轮 ≤2 并发，需要时多轮，只回结论），避免主窗口塞满文件内容。备好仓库现实：
   - 票据状态（含票面 Comments；按 `docs/agents/issue-tracker.md` 词表；读不到或无终态约定→按 orient 内嵌最小词表）
   - `git log --oneline -30`
   - 现行 spec/设计文档（含远端 spec 票正文）
   - repo 有 GLOSSARY.md／docs/adr/／`.out-of-scope/` 则一并纳入

2. **逐文件核验**（只读）。五类检查：
   - **过时**：断言对照仓库逐句验证，记「记忆:行 ↔ 仓库:行」证据；超 30 天未决的「假设：」列入
   - **矛盾**：两条记忆对同一事实说法不同；同文件前后矛盾
   - **越界**：进度细节/✅ 混进现状条目；repo 已记录内容整段复制；平台写入未过两问测试；AGENTS.md 地图与合同脱钩
   - **形态**：现状条目 >10KB、索引行 >150 字符（按字符数，不是字节）、缺日期锚、description 或钩子句与正文脱节（缺正文关键限定＝脱节；措辞风格差异不算）、未标注假设、frontmatter 缺 name/description/type、name 与文件名不符、超 60 天悬挂 [[双链]]
   - **对账**：索引↔文件双向核对——索引有文件无＝断链；文件有索引无＝孤儿
   另做**孤岛排查**：记忆根下找同前缀或关键词撞车的目录（初筛 `grep -il` 只回文件名；Read 候选用 Windows 绝对路径）。**先查全局台账 island-checks.md**——已有结论的目录跳过；发现候选→弹窗附命中关键词列表（词×处数，不展示对方内容）问用户是否同一项目，结论落 island-checks.md。

3. **拍板**：发现按严重度排序，弹窗分批呈报（每批 ≤4 问，推荐项放第一；同类低风险小病可打包成一问「都按推荐处理？全部照办／一条条告诉我」，毒化与过时类逐条呈报）。处置六种：
   - **重写**（重写律）
   - **就地修正**（含补注记、口径澄清）
   - **搬进存档**（完结内容移入 repo 交付存档，记忆留指针）
   - **删除**
   - **合并**（孤岛，防护见下）
   - **重建索引**（仅 MEMORY.md 缺失/损坏：逐文件按 frontmatter 重生成索引行——标题按索引律用 description 中文浓缩，报告注明「标题为重建生成」；整文件重写，索引律唯一例外，经用户拍板后执行）
   **合并防护**（全局台账已有裁决的候选跳过发现问，防护①仍必走——合并前安全步骤）：①先复述两库各 2-3 条代表记忆（取索引钩子句即可）供指认哪库是本项目，口径冲突的逐条对仓库核验；②并入本库的事实加溯源行（「以下 N 条合并自 xxx@日期」）；③旧库废弃并在索引顶部留指针指向本库。合并完成后在 island-checks.md 追加「已合并」行。
   删除／合并的推荐项默认保守（「暂不合并／保留」放第一）。核对后仍有效的红线只标「仍有效」，不动。
   完成＝每条发现都有裁决。

   不许走的捷径：
   - 「抽查几条出全库结论」——五类检查是逐句核验，抽样结论不得冒充全量。
   - 「孤岛候选直接判同项目」——必须先查 island-checks.md，合并防护①不可跳。
   - 「发现顺手改掉不上报」——一切处置经用户拍板，完成＝每条发现都有裁决。

4. **执行**：按裁决批量改，同步 MEMORY.md 索引（单行编辑；重建索引除外）。处置掉的病在台账追加清账行。

5. **报告**：

   ```
   核验 N 条／发现 M 处／处置明细
   下次体检时点：（按收口计数推算）
   尾行：本库 N 条约 X KB，均为普通文件，建议不定期把整个 memory 目录备份到 repo 之外（网盘/移动盘；不进 repo、不参与召回，防误删/换机）
   ```
